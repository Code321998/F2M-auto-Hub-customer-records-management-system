F2M Auto-Hub — Customer Service and Automotive Service Management

Files:
- app.py: Python Flask backend. Serves the website and stores all records
  in a SQLite database (records.db, created automatically on first run).
- render.yaml: Render deployment blueprint (service settings, build and
  start commands, health check).
- requirements.txt: Python dependencies (Flask + Gunicorn for production).
- index.html: page structure (unchanged)
- style.css: visual design and responsive layout (unchanged)
- app.js: page interactions. When the site is served by Flask it saves
  records through the server API; when index.html is opened directly as a
  file it falls back to browser local storage like before.

Run locally:
1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000
Demo login: admin / admin123

Without Python (old demo mode): keep index.html, style.css and app.js in
the same folder and double-click index.html. Records are then saved only
in the current browser on this device.

================================================================================
DEPLOYING TO RENDER
================================================================================

The repository is already prepared with render.yaml, so Render can deploy
it with one click.

1. Push this project to a GitHub repository (see commands below).
2. Go to https://dashboard.render.com and sign in with GitHub.
3. Click "New +" -> "Blueprint" and choose this repository.
4. Render detects render.yaml and shows the f2m-autohub service.
   Click "Apply" / "Deploy".
5. Your site goes live at https://f2m-autohub.onrender.com

If you prefer manual setup instead of the blueprint:
- New + -> Web Service -> connect the repo
- Runtime: Python
- Build Command:  pip install -r requirements.txt
- Start Command:  gunicorn app:app --bind 0.0.0.0:$PORT --threads 4
- Health Check Path: /healthz

Environment variables (set automatically by render.yaml):
- SECRET_KEY: random value generated by Render (used for login sessions).
- PYTHON_VERSION: 3.12.7.

Useful commands to push the project to GitHub the first time:
  git add .
  git commit -m "Prepare F2M Auto-Hub for Render deployment"
  git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
  git push -u origin main

Render is set to auto-deploy: every push to the repository redeploys the site.

IMPORTANT — free plan limitations:
- Free web services spin down after 15 minutes without traffic and take
  about a minute to wake up on the next visit.
- The filesystem on the free plan is EPHEMERAL: records.db is reset every
  time the service redeploys, restarts, or spins down. All records are lost.
- To keep records permanently, either upgrade the instance to a paid plan
  and add a 1 GB persistent disk mounted at /data (then uncomment the
  DATABASE_PATH env var and disks block in render.yaml), or connect a
  Render Postgres database (the free Postgres instance expires after
  30 days).
